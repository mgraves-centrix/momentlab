# UI fidelity and accessibility

- Open the dedicated route reference before implementing that route. Record review in `design/reference-review.md`.
- Rebuild references as semantic React components and live charts. Never ship a reference raster as interface or CSS background.
- Use the canonical routes, four-item mobile navigation, component contracts, and authority order in `UI-IMPLEMENTATION-CONTRACT.md`.
- Use screen 12 as the shared visual system and screen 13 as required state coverage.
- Preserve professional editorial density and exact information hierarchy. Do not add generic dashboard patterns, consumer card styling, decorative gradients, glow, emoji, or an invented mobile composition.
- Meet minimum 44 × 44 px touch targets, visible keyboard focus, landmarks, chart text alternatives, reduced motion, safe areas, contrast, and 200% text zoom.
- UI release requires the documented score of at least 99/100, no category below 98%, and every hard gate in the visual QA contract.
