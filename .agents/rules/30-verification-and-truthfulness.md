# Verification and truthful product behavior

- Keep observations, model inferences, simulated forecasts, and evaluated outcomes explicitly labeled and structurally distinct.
- Display `CONNECTED` only from a healthy authenticated MCP stream. Display `SIMULATED` on seeded forecasts/results and `SYNTHETIC` on generated media.
- Enforce cohort threshold, project isolation, immutable approval audit, and legal finite-state transitions server-side.
- A missing live credential may use a contract-faithful local adapter for development, but the UI and documentation must label the live step blocked. Never present a mock as the partner integration.
- Run the narrowest relevant check after each material change and the complete verification suite at workflow gates.
- Save command, environment, timestamp, outcome, and artifact path for release evidence. Failed checks remain visible until fixed or explicitly blocked.
