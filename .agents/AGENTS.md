# MomentLab UI/UX Standards

- **Primary Action Buttons**: Always build against the `12-system-components.png` and `13-system-states.png` reference files as the source of truth for UI/UX standards. Primary action buttons (e.g., Approve, Launch, Retry) must use the lime green brand color (`var(--lime)`) with black text, NOT purple/violet. Violet is reserved for secondary or conceptual badges, not primary CTA buttons.
